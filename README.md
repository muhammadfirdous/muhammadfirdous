# Muhammad Firdous

### Full-stack development · Applied AI · Developer tools

I build web applications, APIs, and applied machine learning projects with Python, TypeScript, React, and Java. My work spans community resource management, computer vision, knowledge graphs, and interactive tools.

## Selected projects

| Project | What it does | Core technologies |
| --- | --- | --- |
| [Eko Naryn](https://github.com/muhammadfirdous/ekonarynproject) | Recycling management across a public website, admin dashboard, API, and Android app. | Next.js, Express, PostgreSQL, Java |
| [News People Knowledge Graph](https://github.com/muhammadfirdous/News-People-Knowledge-Graph-API) | Extracts people and relationships from news with source provenance and entity resolution. | Python, FastAPI, SQLAlchemy, LLMs |
| [OKLCH Color Picker](https://github.com/muhammadfirdous/OKLCH-Color-Picker) | Interactive color conversion, gamut charts, and a 3D color-space view. | React, TypeScript, Three.js |
| [Machine Learning Dashboard](https://github.com/muhammadfirdous/ML-Final-Project) | Compares neural networks for speech emotion, sentiment, and weather tasks. | TensorFlow, Flask, React, Recharts |
